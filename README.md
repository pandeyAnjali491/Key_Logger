# Key Logger (Demo Website) ⌨️  

This is a **static demo website** built using **HTML, internal CSS, and JavaScript**.  
It was created as a practice project to explore how JavaScript can capture keyboard events and display them on a webpage.  

## Features  
- **Self-contained single HTML file** (HTML + CSS + JS in one place)  
- Demonstrates how JavaScript can listen for and display keystrokes  
- Styled with internal CSS for a clean look  
- Educational project for practicing frontend event handling  

## Tech Stack  
- **HTML5**  
- **CSS3** (internal)  
- **JavaScript** (internal)  

## Purpose  
The main objective of this project is to practice **JavaScript DOM manipulation and event handling**.  
⚠️ This project is built only for **educational and demonstration purposes** — it does not store or misuse keystrokes and should not be considered a malicious keylogger.
